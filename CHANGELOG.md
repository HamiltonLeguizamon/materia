# Changelog

## 0.1.0 — 2026-08-16

Initial stable open-source release candidate.

### Highlights

- Local-first courses, lessons, assessments, progress, and durable generation jobs.
- Traceable agent authoring through the bundled skill and Materia MCP tools.
- Optional read-only research MCPs for Microsoft Learn, AWS Knowledge, and Google Developer Knowledge.
- Typed code, diagram, and canonical image-reference learning artifacts.
- Deterministic offline demo with no credentials or external provider calls.
- Optional browser speech, OpenAI TTS, and portable Kokoro, Qwen, or Chatterbox voice nodes.
- Native standalone operation on macOS, Windows, and Ubuntu, plus an isolated Docker path.
- English-first bilingual interface and independent English or Spanish course content.

### Release boundaries

- Materia is a single-operator local application without authentication for public exposure.
- It does not provide certification guarantees, accounts, billing, analytics, microphone transcription, realtime tutoring, or hosted multi-user operation.
- Provider credentials remain server-side, and paid or local audio generation requires an explicit action.
